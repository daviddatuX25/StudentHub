# **SynapseRT: Title Defense Presentation Script**

**Time Limit**: ~5 Minutes  
**Focus**: Speed, agentic architecture novelty, and definitive academic framing.

---

### **Slide 1: Title & Introduction (15 Seconds)**
* **Slide Visuals**: Formal Title, Registry Code: `BSIT-CAP2-2026-SRT-V2`, and team details in a high-contrast dark interface.
* **Spoken Pitch**:
    > *"Good morning, members of the panel. We propose **SynapseRT**: a Context-Aware Real-Time Salience Pipeline, Offline Agent Harness Engine, and Multi-View Visual Orchestration Framework for Collaborative Environments. Our research focuses on how an intelligent system can process a live stream of conversation, determine what information is valuable, and transform it into targeted visual formats for everyone in the room in real time."*

---

### **Slide 2: The Scene (30 Seconds)**
* **Slide Visuals**: Graphic showing the chaos of high-density sessions vs. clean, role-tailored workspaces.
* **Spoken Pitch**:
    > *"Imagine a fast-paced lecture, a strategic project session, or an intense project review. Words fly by. Traditional text systems can capture the words, but they leave participants with an unreadable wall of text. The room experiences cognitive overload. SynapseRT operates at the critical layer between raw text capture and user display—transforming that mess of words into structured, actionable visual maps live as the conversation unfolds."*

---

### **Slide 3: The Problem (45 Seconds)**
* **Slide Visuals**: Three core problem pillars: 1. Context Blindness, 2. API Isolation, 3. Monolithic UI Inflexibility.
* **Spoken Pitch**:
    > *"Current collaborative tools suffer from three major design flaws. First, they are context-blind—treating a structured lecture and a chaotic creative brainstorm exactly the same. Second, they isolate tools—forcing users to leave the collaborative board to research definitions or fetch external data. Third, they use a rigid, one-size-fits-all UI that ignores the unique needs of different participants, whether they are learning, managing, or taking minutes."*

---

### **Slide 4: The Proposed System & Thesis (60 Seconds)**
* **Slide Visuals**: System Architecture Flow (Speech Ingestion -> Mode Classifier -> Local Edge Agent -> Online Tool Escalation Router -> Visual Taxonomy Router -> Role-Filtered Sync Frontends).
* **Spoken Pitch**:
    > *"Our core thesis is that SynapseRT builds a context-aware salience pipeline. The framework filters raw text using a local session mode classifier. This classifier dictates the information diet of an offline LLM agent running on the edge. This agent uses a custom harness layer to intelligently select, invoke, and synthesize online tools like search or memory retrieval in real-time, delivering clean JSON payloads directly into our UI routing engine."*

---

### **Slide 5: The Visual Form Taxonomy & Role Model (45 Seconds)**
* **Slide Visuals**: Split view mapping information types to the 7 core visual forms (Graphs, Kanban, Timelines) alongside the Role-Rendering matrix.
* **Spoken Pitch**:
    > *"The system matches the extracted data to an optimized visual taxonomy. Relational concepts map to force-directed graphs; action items map to Kanban cards; unresolved questions map to parking lot stacks. These components are synchronized via WebSockets and filtered by role. Students see inline concept cards, facilitators receive pacing updates, and project managers see a clean decision log—all driven by a single application state."*

---

### **Slide 6: The Novelty Claim (30 Seconds)**
* **Slide Visuals**: The Harness Escalation Matrix. Contrast table showing our edge agent orchestration vs. passive cloud wrappers.
* **Spoken Pitch**:
    > *"The core novelty of SynapseRT is not simple offline operations or speech capture—it is our **Local Agent Harness Integration Layer**. We are proving that an offline foundational model can act as a real-time room orchestrator: deciding when to process data locally, when to pull from online tools, and how to inject those results back into a live collaborative surface without breaking the team's creative flow."*

---

### **Slide 7: Scope, Difficulty, & Commitments (45 Seconds)**
* **Slide Visuals**: Core T-Chart (In-Scope Classification and Layout Router vs. Out-of-Scope Hardware DSP and Custom LLM Training) + 3-Phase Milestone Track.
* **Spoken Pitch**:
    > *"Our scope is clearly defined. We map 4 session modes and render 7 visual styles across 3 unique role views. We explicitly treat microphone hardware DSP as an optional capture node, focusing our research purely on information orchestration. We acknowledge the technical risks of context drift and edge latency, which we will solve using temporal sliding stabilization windows. We rate this project as highly complex but completely feasible. Thank you, and we welcome your questions."*
