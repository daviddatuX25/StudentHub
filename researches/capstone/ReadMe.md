# Capstone Titles

This directory holds all six capstone title proposals and their presentation materials.

Each capstone title gets its own folder (`capstone1` through `capstone6`). The idea is simple: treat each title as a standalone project idea that must be pitched and defended individually. The "Student Hub" project lives in `capstone1` — everything there is what this repo builds.

## Per-Title Folder Contents

Each `capstoneN/` folder should contain the four assets from the ppt-guide:

1. **Hook sentence** — written out, rehearsed, not improvised
2. **Architecture sketch** — simple block diagram showing the moving parts
3. **Component map** — five-row table (Web, Mobile, ML, IoT, Mapping)
4. **Novelty statement** — one or two sentences with sourced gap claims

Plus any supporting materials: HTML prototypes, pitch decks, direction docs, etc.

## Key Rule

`ppt-guide.md` stays at this root level — it is the shared framework for all six title defenses. Individual folders hold title-specific materials only.
